# Cover Background Credits

The photo-based audiobook covers use public-domain/CC0 abstract images from Wikimedia Commons.

- `dayspring-of-youth.jpg` uses `Abstract-Artwork- 1345.jpg` by Anthony Ross, CC0 1.0.
- `tam-ly-hoc-cho-su-thay-doi-triet-de.jpg` uses `Geometric Abstract Background.jpg` by Vidsplay from Isorepublic, CC0 1.0.
- `bong-hong-cai-ao.jpg` uses an AI-generated rose-and-fabric background, then local typesetting for the Vietnamese title and author.

The final cover images were cropped, color-treated, and typeset for Stillword.
